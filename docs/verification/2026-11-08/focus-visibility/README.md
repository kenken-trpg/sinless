# フォーカス枠の検証（2026-11-08）

入力欄の既定のフォーカス枠は暗いテーマで `rgb(88, 74, 117)`、入力背景は `rgb(48, 40, 49)` だった。操作リンクの枠は固定のピンク色だった。Sinlessの入力欄・選択欄・テキスト欄・編集欄・操作リンクと内容領域のボタンに、テーマの主文字色を使う2pxの枠を指定した。ヘッダーボタンは暗い背景を持つため、Foundry既存の枠を維持する。

`npm run verify -- focus-visibility` でキャラクター名、出自選択、ライフスタイル操作、内容領域のアイコンボタン、射撃技能ランクを測る。Tabの後に各対象へフォーカスを移し、`:focus-visible` と実線枠を確認する。撮影画像の上辺中央の枠画素と、その3px外側の画素を比較し3:1以上を確認する。遷移アニメーションはこの検証コンテキストだけで無効にする。

日本語・英語それぞれ、明暗テーマで計10例が成功。結果は `ja.json`・`en.json`。ページエラー0、作成アクターの削除とUI設定復元も成功。英語では既存の `keyboard` 検証も通過（全アクター種別の各タブ、全アイテム種別、Enter/Spaceと子画面からの復帰）。`npm run check` は151テスト、翻訳キー整合性、構文チェックが成功。

これは代表例の枠の測定であり、全画面のコントラストや遮蔽、実スクリーンリーダー、WCAG全体への適合を確認するものではない。ブラウザーはChromium、Foundry 14.365。英語の最初の検証時はsystemの読み込み表示が0.15.14（ソースは0.15.15と今回の変更）だったため、日本語の最終確認ではワールドを再起動して0.15.15を読み込んだ。
