# 幅320pxのシート検証（2026-11-08）

Foundry 14.365、system 0.15.14 に今回のCSS変更を適用。ブラウザーのビューポートは1600×1100、文字サイズは標準（font scale 5）。アクターと武器のシートを320px幅にする。ほかのウィンドウとチャットカードは既定幅で検査するため、ビューポート全体を320pxにする検証や WCAG 全体への適合判定ではない。

修正前は日本語のブランドアクション一覧が379pxに広がり、リソース名の列は15pxまで縮んだ。アクション一覧・残りアクション数・リソース操作を狭い幅では縦に並べて解消した。英語では特性名が固定4列からはみ出したため、能力値と特性の列数も内容幅に合わせるようにした。

```sh
npm run verify -- reflow
SINLESS_VERIFY_LANGUAGE=en npm run verify -- reflow text-resize text-spacing
```

既存のPlaywrightを `SINLESS_PLAYWRIGHT` で指定。日本語・英語のリフロー各24画面で問題0。英語の200%文字拡大と文字間隔も各24画面で問題0。すべてページエラー0、テスト用データの削除とUI設定の復元に成功。結果のJSONはこのフォルダーに保存。

`npm run check` は151テスト、翻訳キー整合性、構文チェックが成功。
