# 検証用チャットの削除範囲（2026-11-08）

`color-independence`・`contrast`・`target-size` は、開始時のチャットIDを保存し、終了時にそれ以外を削除していた。検証中に別セッションで投稿された無関係なチャットも削除対象になるため、各検証自身が作ったカードのIDだけを削除するよう修正した。残存アクターの確認も名前の接頭辞から作成IDへ変更した。

追加の回帰検証:

```sh
npm run verify -- chat-cleanup
```

既存のPlaywrightを `SINLESS_PLAYWRIGHT` で指定する。`all` の19本とは別の追加検証で、対象3本を子プロセスとして実行する。一時GMユーザーを作り、対象がカードを作った後、別セッションから無関係なチャットを追加する。各子プロセスの成功後、追加チャットと実行前の全チャットが残ることを確認する。回帰検証自身が作ったメッセージと一時GMは終了時に削除する。

Foundry 14.365、ソース0.15.17に今回の検証修正を適用、日本語で実行。3本とも無関係な投稿と実行前のチャットを保持（`preservation.json`）。表示検証も成功:

- 色に依存しない表示: ダイス・リソース・強制カラーモードの確認、ページエラー0、自分のアクターとカードを削除。
- コントラスト: 明暗両テーマの2,006箇所、問題0、ページエラー0、テーマ復元と自分のアクター・カードの削除。
- 操作対象サイズ: 49画面・1,810箇所、問題0、ページエラー0、ワールド設定復元と自分のアクター・カードの削除。

`npm run check` は151テスト、翻訳キー整合性、182ファイルの構文チェックが成功。この変更は検証ツールの修正であり、ゲームシステムの実行時動作は変更しない。強制終了時の回復や、ここに挙げた3本以外の削除処理は今回の確認対象外。
