# サンプル検証のチャット削除範囲（2026-11-08）

サンプル検証は開始後のメッセージのうち、実行GMが作者であるものをすべて削除していた。同じGMの無関係な投稿まで対象になるため、検証用アクターの発言者ID、検証用シーン、または `flags.sinless.actorUuid` が検証用アクターに一致するものだけを削除するようにした。既存チャットは開始時IDの照合で除外する。

後片付けはアクター・シーン・戦闘・関連チャットの残存もassertで確認する。

```sh
npm run verify -- sample-chat-cleanup
```

`SINLESS_PLAYWRIGHT` で既存Playwrightを指定。`all` の19本とは別の追加検証。サンプルの最初の判定カードの後に、一時GMセッションから別ユーザーのチャットと実行GMと同じ作者IDのチャットを追加する。後者はFoundry v14の `author` フィールドを使い、作者IDが実行GMに一致することも確認する。終了後に追加チャット2件と既存チャットが残ることを確認し、回帰検証自身が作ったチャットと一時ユーザーを削除する。

Foundry 14.365 / Sinless 0.15.18、日本語で実行。保持の確認4項目がすべて成功（`preservation.json`）。サンプル検証の25項目は失敗なし、ページエラー0。作成アクター・シーン・戦闘・関連チャットの残存はすべて0件（`samples-summary.json`）。JSONとコンペンディウムの読み込み、主要判定、戦闘ラウンドのプール回復も実行した。

`npm run check` は151テスト、翻訳整合性、186ファイルの構文チェックが成功。変更は検証ツールと記録のみ。

今回の範囲外として、`current/fixtures.mjs` の通常終了時の後片付けは開始後の全アクター・アイテム・シーン・戦闘・チャットを削除するため、別途修正が必要。中断時の復旧処理との整合と、元スクリプトによる既存戦闘の削除も合わせて確認する必要がある。
