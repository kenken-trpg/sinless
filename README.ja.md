# Sinless for Foundry VTT（非公式）

TRPG **Sinless** を Foundry Virtual Tabletop で遊ぶための、非公式のファンメイド・システムです。
出版社とは無関係で、承認も受けていません。プレイにはルールブックが必要です（ルール本文は含みません）。

## 主な機能

- キャラクター／NPC アクター。6能力値、4つのダイスプール（剛力・技巧・集中・決意）を
  Sinless の端数処理で自動計算。肉体／朦朧コンディション・トラックと負傷ペナルティ、
  エチケット、キスメット・プール、ゾエティック・ポテンシャル。
- 判定ダイアログ：上限（技能＋装備）、ボーナス／ペナルティダイス（ペナルティはまずボーナスを相殺）、
  グループ技能での代用（−2）、未修得（4成功＝1成功）、出目1／1・2の振り直し、
  キスメット・ダイス、衝突中のプール消費。
- チャットカード：成功数、アーグル・バーグル・フーファロウ判定、判定後のキスメット追加ボタン。
- 攻撃カードはターゲット中のトークンを記録する。防御側はダメージダイアログを開き、回避とソークをその場でロールできる。
  ダイアログが計算するアーマーの扱い：
  - 対弾アーマーと貫通の比較（朦朧／肉体）
  - 対衝撃アーマーからアーマー貫通を引く
  - エネルギー兵器によるアーマー損耗
  - 爆発
  その後コンディショントラックに書き込む（朦朧→肉体→超過とあふれる）。
- NPC はクリーチャー・ルールの固定防御ダイス（回避／ソーク／抵抗）を使える。プールは消費しない。
  空欄ならプレイヤーと同じくプールから振る。武器にも同様に固定の攻撃ダイスを設定できる。
- アクター・アイテムのアクティブ・エフェクト。アイテムの効果は、防具なら装備中、装備品なら携帯中だけ適用される。
  インプラントの効果は常に適用される。主な変更キー：
  - `system.attributes.str.value`
  - `system.pools.brawn.bonus`
  - `system.condition.physical.bonus`
  - `system.armorBonus.ballistic`
  - `system.skills.firearms.rank`
  - `system.initiativeBonus`
  - `system.zoetic.bonus`
  能力値の欄は元の値のまま表示され、編集できる。それ以外で効果が値を設定している欄はロックされる。
- イニシアチブ＝反応＋集中プール全部の成功数。NPC は固定値。戦闘ラウンドごとにプール自動回復。
- ワールド設定：ラン難易度（ベテラン／プロフェッショナル／プライム）、オペレーショナル・ヒート、
  コンディション基本マス数、負傷ペナルティの有無。
- アイテム：武器、防具、装備品、インプラント、呪文／能力、儀式、知識技能、アセット、リソース。
- セクター・プレイ用のブランド・アクター：5つの能力値、ブランド特性、時価総額／維持費／貯蓄、
  セクター・ヒートの効果、セクター・アクション判定（ヒート上昇・有能の自動成功）、ターン終了時の繰り入れ、
  ダメージ／影響力トラック付きのリソース、メンバー管理、最適なメンバーによるアセット判定。
- 最初から多言語対応（英語・日本語）。

## 開発

ビルド不要です（Foundry が ES モジュールを直接読み込みます）。

```sh
ln -s "$PWD" "<FoundryData>/Data/systems/sinless"
npm test             # ルールの単体テスト＋i18n チェック
npm run check:i18n   # 言語ファイルのキー・プレースホルダ整合性
npm run build        # dist/sinless.zip を作成
```

表示文字列は直接書かず、必ず `lang/en.json` と `lang/ja.json` の両方にキーを追加してください。
訳語は暫定です。用語集の確定に合わせて `lang/ja.json` を更新してください。
