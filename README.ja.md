# Sinless for Foundry VTT（非公式）

TRPG **Sinless** を Foundry Virtual Tabletop で遊ぶための、非公式のファンメイド・システムです。
出版社とは無関係で、承認も受けていません。プレイにはルールブックが必要です（ルール本文は含みません）。

## 主な機能

- キャラクター／NPC アクター。6能力値、4つのダイスプール（剛力・技巧・集中・決意）を
  Sinless の端数処理で自動計算。肉体／朦朧コンディション・トラックと負傷ペナルティ、
  エチケット、キスメット・プール、ゾエティック・ポテンシャル。
- 判定ダイアログ：上限（技能＋装備）、ボーナス／ペナルティダイス（ペナルティはまずボーナスを相殺）、
  グループ技能での代用（−2）、未修得（4成功＝1成功）、出目1／1・2の振り直し、
  キスメット・ダイス、衝突中のプール消費。
- チャットカード：成功数、アーグル・バーグル・フーファロウ判定、判定後のキスメット追加ボタン。
- イニシアチブ＝反応＋集中プール全部の成功数。NPC は固定値。戦闘ラウンドごとにプール自動回復。
- ワールド設定：ラン難易度（ベテラン／プロフェッショナル／プライム）、オペレーショナル・ヒート、
  コンディション基本マス数、負傷ペナルティの有無。
- アイテム：武器、防具、装備品、インプラント、呪文／能力、儀式、知識技能、アセット。
- 最初から多言語対応（英語・日本語）。

## 開発

ビルド不要です（Foundry が ES モジュールを直接読み込みます）。

```sh
ln -s "$PWD" "<FoundryData>/Data/systems/sinless"
npm test             # ルールの単体テスト＋i18n チェック
npm run check:i18n   # 言語ファイルのキー・プレースホルダ整合性
npm run build        # dist/sinless.zip を作成
```

表示文字列は直接書かず、必ず `lang/en.json` と `lang/ja.json` の両方にキーを追加してください。
訳語は暫定です。用語集の確定に合わせて `lang/ja.json` を更新してください。
