## Active Effects / アクティブ・エフェクト

**English**
- New **Effects** tab on character and NPC sheets, listing the actor's own effects and those transferred from items (with their source). Create, enable/disable, edit and delete from the list.
- Item sheets have an effects list: give an implant `system.attributes.str.value +2` and it applies as soon as the character owns it.
- Item effects apply only while armor is **equipped** and gear is **carried**; implant effects always apply.
- New bonus fields as effect targets: `system.pools.<pool>.bonus` and `system.condition.physical|stun.bonus`. Existing targets also work: `system.armorBonus.*`, `system.initiativeBonus`, `system.kismet.poolBonus`, `system.zoetic.bonus`, skill and etiquette ranks.
- Attribute inputs keep showing the base value, with the modified value next to the label. Other inputs whose value an effect sets are locked, so the effect isn't saved into the base data.
- Supports both the v14 (`system.changes`) and v13 (`changes`) effect formats. Tested on v14.

**日本語**
- キャラクター／NPC シートに「効果」タブを追加しました。アクター自身の効果と、アイテムから来る効果（出所付き）を一覧表示し、作成・有効／無効・編集・削除ができます。
- アイテムシートに効果一覧を追加しました。インプラントに `system.attributes.str.value +2` を付ければ、持たせるだけで適用されます。
- アイテムの効果は、防具なら**装備中**、装備品なら**携帯中**だけ適用されます。インプラントは常に適用されます。
- 効果で変更できるボーナス欄を追加しました：`system.pools.<プール>.bonus`、`system.condition.physical|stun.bonus`。既存の `system.armorBonus.*`、`system.initiativeBonus`、`system.kismet.poolBonus`、`system.zoetic.bonus`、技能やエチケットのランクも使えます。
- 能力値の欄は元の値のまま表示し、効果適用後の値をラベルの横に出します。それ以外で効果が値を決めている欄はロックされます（効果分が元データに保存されてしまうのを防ぐため）。
- v14（`system.changes`）と v13（`changes`）の両方の形式に対応しています。動作確認は v14 で行いました。

Reload after updating. / 更新後は再読み込みのみで使えます。
