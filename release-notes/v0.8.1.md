## Automated releases / リリースの自動化

**English**
- No gameplay changes. This is the first release published by GitHub Actions.
- CI runs the unit tests, localization and syntax checks and the package build on every push and pull request.
- Pushing a version tag verifies it against `system.json` and `package.json`, builds the package and publishes this release.
- The README describes the release procedure. Past release notes are kept in `release-notes/`.

**日本語**
- ゲーム内容の変更はありません。GitHub Actions が公開する最初のリリースです。
- push と PR ごとに、CI がユニットテスト、翻訳チェック、構文チェック、パッケージのビルドを実行します。
- バージョンのタグを push すると、`system.json` と `package.json` との一致を確認し、ビルドしてこのリリースを公開します。
- README にリリース手順を追加しました。過去のリリースノートは `release-notes/` に保存しています。

Reload after updating. / 更新後は再読み込みのみで使えます。
