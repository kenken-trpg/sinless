## Help, chase and operation buttons without a canvas / キャンバスがないときのヘルプ・チェイス・作戦ボタン

**English**
- Fixed: the help, car chase and operation buttons in the token controls did nothing while no canvas was ready: no scene in the world, no scene viewed, or "Disable Game Canvas" turned on. They now open their windows in every case.
- Internal: repeated code in the actor sheets and the chat card buttons is shared. Behavior is unchanged.

**日本語**
- 修正：キャンバスの準備ができていないとき(ワールドにシーンがない、シーンを表示していない、「ゲームキャンバスを無効化」がオン)、トークン操作のヘルプ・カーチェイス・作戦のボタンを押しても何も起きませんでした。どの場合でも窓が開くようになりました。
- 内部の変更：アクターシートとチャットカードのボタンで重複していたコードをまとめました。動作は変わりません。

Validation: 139 tests, localization and syntax checks passed. In Foundry 14.365 with 0.14.1 loaded, all nine browser scripts passed, including help-window, which now clicks the help button with and without the canvas, and the new sheet-actions, which presses every kind of actor sheet button.
