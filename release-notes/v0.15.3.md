## Keyboard access for sheet actions / シート操作のキーボード対応

**English**
- Sheet action links can now be reached with Tab and activated with Enter or Space. Focus stays on the same control when a sheet re-renders, except when the action opens a dialog.
- Track boxes and toggle controls now expose their names and pressed state to assistive technology. A visible accent outline marks the keyboard focus.
- Added a keyboard browser verification and included it in the full verification run.

**日本語**
- Tab でシートの操作に移動し、Enter または Space で実行できるようになりました。シートが描き直されても、ダイアログを開く操作を除き、同じ操作にフォーカスを戻します。
- トラックのボックスと切り替え操作に、支援技術向けの名前と押下状態を追加しました。キーボードでのフォーカス位置はアクセント色の枠で表示します。
- キーボード操作のブラウザー検証を追加し、全検証の実行対象に含めました。

Validation: 145 tests passed. After restarting the Foundry world, all 10 scripts in `verify -- all` passed. The test world was restored to an empty state.
