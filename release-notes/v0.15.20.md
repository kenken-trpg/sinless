## Non-text contrast / 文字以外のコントラスト

**English**
- Inputs, selects and textareas in Sinless windows now draw a visible edge in the dark theme. Foundry's dark fields have a transparent border and a fill of only 1.4:1 against the window; the edge uses the muted text color, above 3:1 in both themes (WCAG 2.2 1.4.11).
- Empty condition monitor boxes and brand resource boxes use the same edge color.
- Checkboxes get a thin ring, so an unchecked box stays visible in the dark theme and a checked box stands out from parchment in the light theme (the orange was 1.5:1).
- The heat stars in the operation window no longer use a fixed gray or bright amber, which were 2.26:1 and 1.32:1 on parchment.
- Added `npm run verify -- non-text-contrast`, which measures the edges of fields, checkboxes, condition and resource boxes and dice, and the icons of icon-only controls, in dark and light themes. The full verification run now contains 20 scripts.

**日本語**
- Sinless のウィンドウの入力欄・選択欄・テキスト欄に、ダークテーマでも見える枠を付けました。Foundry のダークテーマの入力欄は枠が透明で、塗りとウィンドウのコントラストは 1.4:1 しかありません。枠は控えめな文字色で、両テーマで 3:1 を超えます(WCAG 2.2 の 1.4.11)。
- 空の状態モニターのマスとブランドのリソースのマスも同じ枠の色にしました。
- チェックボックスに細い輪郭を付けました。ダークテーマでオフのチェックボックスが見え、ライトテーマでオンのチェックボックスが羊皮紙から区別できます(オレンジは 1.5:1 でした)。
- オペレーション画面のヒートの星は、固定の灰色と明るい琥珀色をやめました。羊皮紙の上で 2.26:1 と 1.32:1 でした。
- 入力欄・チェックボックス・状態モニターとリソースのマス・ダイスの境界と、アイコンだけのボタンのアイコンを明暗テーマで測る `npm run verify -- non-text-contrast` を追加しました。全体の検証は 20 本です。

Validation: 152 tests, localization and syntax checks passed. On Foundry 14.365, `non-text-contrast` passed in Japanese and English (1,416 boundaries and 458 icons each, across dark and light themes); without the style changes it reported 17 failing groups. `contrast`, `focus-visibility`, `color-independence`, `text-resize`, `keyboard-dialogs` and `target-size` passed with the changes. This measures representative windows with the sample actors; it is not a full WCAG conformance audit.
