## Input labels for assistive technology / 支援技術向けの入力欄ラベル

**English**
- Form captions on sheets and dialogs are now linked to their inputs. Compound rows have distinct names in English and Japanese, so screen readers can tell apart fields such as skill rank and specialization, or attribute base and maximum. Sheet headers and trackers are covered too.
- Rich text edit buttons are no longer hidden until hover. They can be reached with Tab and are named after their field. Opening one focuses the editor, and saving returns focus to the edit button.
- Added the missing localization for software actions and brand notes.
- Keyboard browser verification now reads Chromium's accessibility tree to check field names, roles, states (checked, selected, disabled) and multiline editors. `SINLESS_VERIFY_LANGUAGE=en|ja` sets the language for a verification run. Actual VoiceOver and NVDA speech is not tested.

**日本語**
- シートとダイアログの入力欄を、表示されている見出しと結び付けました。技能のランクと専門、能力値の基本値と最大値のように、1 行に並ぶ入力欄にも英語・日本語で別々の名前を付け、スクリーンリーダーで区別できるようにしました。シートのヘッダーとトラッカーも対象です。
- リッチテキストの編集ボタンは、ホバーしなくても表示されるようになりました。Tab で移動でき、項目名が付いています。開くと編集欄にフォーカスが移り、保存すると編集ボタンに戻ります。
- ソフトウェアのアクションとブランドのメモに、足りなかった翻訳を加えました。
- キーボードのブラウザー検証で、Chromium のアクセシビリティツリーから入力欄の名前・役割・状態(チェック・選択・無効)と複数行の編集欄を確認するようにしました。`SINLESS_VERIFY_LANGUAGE=en|ja` で、検証時の言語を指定できます。VoiceOver・NVDA での実際の読み上げは確認していません。

Validation: 145 tests, localization and syntax checks passed. On Foundry 14.365 with Sinless 0.15.7, the full browser verification passed: 11 scripts in one run, and `batch` (73 checks) on a separate rerun after leftover fixtures from an earlier run were removed. The keyboard, keyboard-dialogs and keyboard-apps checks also passed with the browser language set to English.
