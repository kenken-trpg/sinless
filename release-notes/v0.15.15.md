## Narrow brand sheets / 狭いブランドシートの表示

**English**
- Brand sheets now stack the action count, action details and resource controls when the content area is 24rem or narrower, keeping resource names and summaries readable.
- Brand statistics and traits use fewer columns at narrow widths, preventing long English trait names from overflowing.
- Added `npm run verify -- reflow` to check actor and weapon sheets at 320px with the default text size. The full verification run now contains 18 scripts. Other windows and chat cards retain their default widths during this check.

**日本語**
- ブランドシートの内容領域が24rem以下になると、残りアクション数・アクションの詳細・リソース操作を縦に並べ、リソース名と概要が押しつぶされないようにしました。
- ブランド能力値と特性の列数を狭い幅に合わせて減らし、英語の長い特性名のはみ出しを防ぎました。
- 標準の文字サイズでアクターと武器のシートを幅320pxにして確かめる `npm run verify -- reflow` を追加しました。全体の検証は18本です。この検証では、ほかのウィンドウとチャットカードは既定幅で確認します。

Validation: 151 tests, localization and syntax checks, and package build passed. On Foundry 14.365 with system 0.15.14 plus these changes, Japanese and English reflow checks passed in 24 views each. English 200% text-resize and text-spacing checks also passed in 24 views each. All runs reported no page errors and successful fixture cleanup and settings restoration. This checks sheet widths, not a 320px browser viewport or all WCAG requirements.
