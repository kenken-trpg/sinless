## Readable text contrast / 読みやすい文字のコントラスト

**English**
- Muted text, hints and placeholders now meet WCAG AA contrast (4.5:1) in both the dark and light themes. The muted color mixes Foundry's subtle text color with the primary text color, so it follows the theme.
- Dice on test cards are no longer faded. Unsuccessful dice, Kismet dice and ones were between 2.4:1 and 3.8:1 on the parchment. The green success fill and the red 1 are unchanged.
- Hints, notes and counts in sheets, the test dialog, and the operation, chase and advancement windows use the muted color instead of transparency. Defeated pursuers and disabled effects are struck through as well as muted.
- Added the `contrast` browser verification. It covers every actor sheet tab, the help, operation and chase windows, a test dialog and a chat card, in both themes, and reads backgrounds from a screenshot. The full verification run now contains 14 scripts.

**日本語**
- 控えめな文字・説明文・プレースホルダーが、ダーク・ライトどちらのテーマでも WCAG AA のコントラスト(4.5:1)を満たすようになりました。控えめな文字の色は、Foundry の控えめな色に通常の文字色を混ぜたもので、テーマに合わせて変わります。
- 判定カードのダイスを薄く表示するのをやめました。成功しなかったダイス、キスメット・ダイス、1 の目は、羊皮紙の背景に対して 2.4〜3.8:1 しかありませんでした。成功ダイスの緑の塗りつぶしと、1 の目の赤は変わりません。
- シート、判定ダイアログ、オペレーション・チェイス・成長の画面の説明文・注記・数は、透明度で薄くする代わりに控えめな色を使うようにしました。脱落した追跡者と無効の効果は、控えめな色に加えて取り消し線で示します。
- ブラウザー検証 `contrast` を追加しました。全種類のアクターシートの全タブ、ヘルプ・オペレーション・チェイスの画面、判定ダイアログ、チャットカードを、両テーマで確認します。背景はスクリーンショットから読み取ります。全体の検証は 14 本になりました。

Validation: 147 tests, localization and syntax checks passed. On Foundry 14.365, all 14 browser verification scripts passed. The contrast and color-independence checks also passed with the browser language set to English (2,010 texts measured).
