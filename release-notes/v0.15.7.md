## Keyboard focus in tracker windows / トラッカー画面のキーボードフォーカス

**English**
- Keep keyboard focus through consecutive renders, such as an operation heat change followed by its state update. Native action buttons and focused form changes are now included. When a control disappears, focus moves to a nearby control.
- Added keyboard browser verification for help, operation and chase windows, including cancellation and focus return from child sheets. The full verification run now contains 12 scripts.
- Help language selection is checked through a focused selection change; arrow-key selection could not be reproduced in the headless browser.

**日本語**
- オペレーションのヒート変更など、画面が続けて描き直される場合もキーボードフォーカスを保ちます。通常の操作ボタンとフォーカス中の入力変更にも対応し、操作した要素が消えた場合は近くの操作へフォーカスを移します。
- ヘルプ・オペレーション・チェイスのキーボード検証を追加しました。キャンセルや子画面を閉じた後の復帰も確認し、全検証は12本になりました。
- ヘルプの言語選択は、フォーカス中の選択変更で確認しています。矢印キーによる選択変更はheadlessブラウザーでは再現できず、未確認です。

Validation: 145 tests, localization and syntax checks passed. The keyboard-apps, keyboard and keyboard-dialogs browser checks each passed after relaunch on Foundry 14.365 with Sinless 0.15.6. Temporary data was removed and original world settings were verified restored.
