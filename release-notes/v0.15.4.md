## Restore focus after dialogs / ダイアログ終了後のフォーカス復帰

**English**
- Closing a sheet dialog now returns keyboard focus to the control that opened it. This covers Escape, the window close button, and cancellation, without moving focus away from another application.
- Lifestyle action links no longer also activate the lifestyle select inside the same label.
- Expanded browser verification to traverse all seven character sheet tabs with Tab and Shift+Tab, including input fields, and to check dialog focus return.

**日本語**
- シートから開いたダイアログを閉じると、元の操作にキーボードフォーカスを戻します。Escape、ウィンドウの閉じるボタン、キャンセルに対応し、別のアプリケーションへ移ったフォーカスは引き戻しません。
- 生活費の操作リンクを押したとき、同じラベル内の生活水準の選択欄まで反応する問題を修正しました。
- 入力欄も含めたキャラクターシート全7タブのTab・Shift+Tab移動と、ダイアログ終了後のフォーカス復帰をブラウザー検証に追加しました。

Validation: 145 tests, localization and syntax checks passed. The expanded keyboard browser verification passed after restarting the world with Sinless 0.15.3 on Foundry 14.365. Test documents were removed afterward.
