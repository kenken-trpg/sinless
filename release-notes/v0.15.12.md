## Translated dialog buttons / ダイアログのボタンの翻訳

**English**
- The Cancel button of every Sinless dialog and the Yes/No buttons of the confirmation dialogs now come from Sinless's own translations. They used Foundry's built-in labels, which are English only, so they stayed English in a Japanese world unless a core translation module was installed.
- The affected dialogs are the test, damage, digital, drain, Kismet award, advancement, boon, operation, chase and sustained spell dialogs, sheet confirmations such as deleting an item, and the confirmation for replacing the help journal.
- A unit test now rejects Foundry's built-in button labels in Sinless code.

**日本語**
- Sinless のすべてのダイアログのキャンセルボタンと、確認ダイアログのはい/いいえボタンを、Sinless 自身の翻訳で表示するようにしました。これまでは Foundry 本体のラベルを使っていました。本体のラベルには英語しかないため、本体の日本語訳を入れていない環境では、日本語のワールドでも英語のまま表示されていました。
- 対象は、判定・ダメージ・デジタル・ドレイン・キスメット付与・成長・恩恵・オペレーション・チェイス・持続呪文のダイアログ、アイテムの削除などシートでの確認、ヘルプのジャーナルを置き換えるときの確認です。
- Sinless のコードで Foundry 本体のボタンラベルを使うと失敗する単体テストを加えました。

Validation: 149 tests, localization and syntax checks passed. On Foundry 14.365, all 15 browser verification scripts passed. The keyboard checks also passed with the browser language set to English. The delete confirmation, test dialog and Kismet award dialog were opened in both languages and showed the translated button labels.
