## Scrolled keyboard focus verification / スクロール後のフォーカス検証

**English**
- Expanded `npm run verify -- keyboard` with a long gear-list regression check. It creates 35 gear items and exercises the last row at standard width, 320px width and 200% text size.
- Checks that Space and Enter toggle carried state, focus stays visible after re-rendering, and opening and closing the item sheet returns visible focus to the edit control.
- Records Japanese and English results. This release adds verification and documentation; it does not change runtime behavior.

**日本語**
- `npm run verify -- keyboard` に長い装備一覧の回帰検証を追加しました。装備35件を作り、通常幅・幅320px・200%文字拡大で末尾の行を操作します。
- SpaceとEnterで携行状態が変わること、描き直し後もフォーカスが見えること、装備編集画面を開いて閉じると元の編集ボタンにフォーカスが戻って見えることを確認します。
- 日本語・英語の結果を記録しました。今回は検証とドキュメントの追加で、実行時の動作変更はありません。

Validation: 151 tests, localization and syntax checks, and package build passed. On Foundry 14.365 / system 0.15.16, Japanese and English keyboard runs passed, including all three new scroll conditions, all actor and item types, and no page errors. The added fixture checks actor removal and UI restoration. Visibility is tested at the control center; this is not a full outline, obstruction or WCAG conformance audit.
