## Text spacing and wrapped controls / 文字間隔とボタンの折り返し

**English**
- Buttons in Sinless windows and chat cards grow with wrapped labels, keeping text inside the button when text size or spacing is increased.
- Chat card headers wrap so the target number can move below the title without squeezing its text.
- Added `text-spacing` browser verification with WCAG 1.4.12 spacing. Expanded text-resize verification to include chat cards and vertical text overflow. Text-width measurements include letter and word spacing.

**日本語**
- Sinless のウィンドウとチャットカードのボタンは、文字サイズや文字間隔を広げてラベルが折り返すと、文字に合わせて高くなるようにしました。
- チャットカードの見出しを折り返せるようにし、目標値が狭く押しつぶされず、題の下に回るようにしました。
- WCAG 1.4.12 の文字間隔を適用するブラウザー検証 `text-spacing` を追加しました。文字拡大の検証にチャットカードと縦方向の文字のはみ出しを追加し、文字幅の測定にも文字間隔・単語間隔を反映しました。

Validation: 151 tests, localization and syntax checks passed. On Foundry 14.365 with system 0.15.13 plus these changes, text-spacing and 200% text-resize checks passed in 24 views each in Japanese and English. Target-size checks passed in 49 views (1,810 Japanese and 1,809 English targets). All six browser runs reported no page errors and successful fixture cleanup and settings restoration. These checks cover the documented views, not all WCAG requirements.
