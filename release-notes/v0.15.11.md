## Large text and narrow windows / 大きな文字と狭いウィンドウ

**English**
- Sheets and dialogs now stay usable at Foundry's largest font scale (200%). Previously, selects showed a single character, names and headings were cut off or wrapped one character per line, attributes did not fit their grid, and skill names were squeezed.
- Layouts change based on the window's content width measured in text size, so the same rules apply when text is enlarged and when a window is made narrow. Narrow sheets scroll as a whole, including the header. Headers, tabs, attributes, skills, pools and item rows wrap instead of shrinking, and item summaries move below the item name. In narrow dialogs, labels sit above their inputs.
- The content of every Sinless window can now be scrolled vertically. The test dialog, operation and help windows could not be scrolled to their end at large text sizes.
- Layout at the normal text size is unchanged.
- Added the `text-resize` browser verification. It opens every actor sheet tab, an item sheet, the help, operation and chase windows and a test dialog. It fails on content that is cut off, cannot be scrolled, is clipped, or is squeezed. The full verification run now contains 15 scripts.

**日本語**
- Foundry の文字サイズを最大(200%)にしても、シートとダイアログを使えるようにしました。これまでは、選択欄に 1 文字しか見えず、名前や見出しが切れたり 1 文字ずつ折り返したりし、能力値が枠に入りきらず、技能名が押しつぶされていました。
- ウィンドウの内容部分の幅を文字の大きさを基準に測り、レイアウトを切り替えます。そのため、文字を大きくしたときにも、ウィンドウを狭くしたときにも、同じ規則が働きます。狭いシートは、ヘッダーを含めて全体がスクロールします。ヘッダー・タブ・能力値・技能・プール・アイテム行は、縮める代わりに折り返し、アイテムの概要はアイテム名の下に回ります。狭いダイアログでは、見出しを入力欄の上に置きます。
- Sinless のすべてのウィンドウで、内容部分を縦にスクロールできるようにしました。大きな文字では、判定ダイアログ・オペレーション・ヘルプの画面を最後までスクロールできませんでした。
- 標準の文字サイズでのレイアウトは変わりません。
- ブラウザー検証 `text-resize` を追加しました。全種類のアクターシートの全タブ、アイテムシート、ヘルプ・オペレーション・チェイスの画面、判定ダイアログを開き、内容の切れ・スクロールできないはみ出し・文字の欠け・押しつぶしがあれば失敗にします。全体の検証は 15 本になりました。

Validation: 148 tests, localization and syntax checks passed. On Foundry 14.365, all 15 browser verification scripts passed. The text-resize and keyboard checks also passed with the browser language set to English. Text-resize passed in Japanese at font scales 5 to 10, in English at 5 and 10, and in both languages with 400px sheets.
