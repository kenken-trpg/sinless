## Character sheet scrolling / キャラクターシートのスクロール修正

**English**
- Fix actor sheet content being clipped when it exceeds the window height.
- Keep the character header and tab navigation visible while scrolling tab content.
- Allow scrolling in smaller windows and preserve the scroll position when a tab is rendered again.

**日本語**
- キャラクターシートで、ウィンドウの高さを超えた内容が隠れて見られなくなる問題を修正しました。
- キャラクター情報とタブの見出しを上部に残したまま、各タブの内容を縦にスクロールできます。
- 小さくしたウィンドウでも下まで表示でき、タブの再描画時もスクロール位置を保持します。

Reload after updating. / 更新後は画面を再読み込みしてください。
