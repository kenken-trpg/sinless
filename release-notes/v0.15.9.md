## States shown without relying on color / 色に頼らない状態表示

**English**
- Dice on test cards now carry screen reader text for successful and rerolled dice, such as "5 (success)". The visible card is unchanged.
- Brand resource tracks are read as one item, for example "9 boxes: 3 damaged, 2 influenced, 1 demolished". On screen, damaged boxes show a cross and influenced boxes a slash, so the states no longer depend on red and green alone.
- Active toggles in item rows are underlined as well as colored. An active alert response in the operation window is announced as text, not only by its warning icon.
- In high contrast mode (Windows `forced-colors`), filled condition boxes, successful dice, resource marks and toggle underlines stay visible.
- Added the `color-independence` browser verification. It reads Chromium's accessibility tree and emulates forced colors. The full verification run now contains 13 scripts. Real Windows High Contrast display and actual screen reader speech are not tested.

**日本語**
- 判定カードの成功ダイスと振り直したダイスに、スクリーンリーダー用の文字を加えました(例:「5(成功)」)。カードの見た目は変わりません。
- ブランドのリソース欄を、1 つの項目として読み上げるようにしました(例:「9 マス: ダメージ 3・影響力 2・破壊済み 1」)。画面上ではダメージのマスに×、影響力のマスに斜線を描くので、赤と緑の区別だけに頼らなくなりました。
- アイテム行の切り替えボタンは、オンのとき色に加えて下線が付きます。オペレーション画面で発動中のアラート対応は、警告アイコンだけでなく文字でも読み上げます。
- ハイコントラストモード(Windows の `forced-colors`)でも、状態モニターの埋まったマス、成功ダイス、リソース欄の印、切り替えボタンの下線が見えるようにしました。
- ブラウザー検証 `color-independence` を追加しました。Chromium のアクセシビリティツリーを読み、ハイコントラストモードを模擬して確認します。全体の検証は 13 本になりました。実際の Windows のハイコントラスト表示と、スクリーンリーダーの読み上げは確認していません。

Validation: 146 tests, localization and syntax checks passed. On Foundry 14.365, all 13 browser verification scripts passed. Three of them (magic, player, help-window) passed on a rerun after the world's default scene was made active again. The color-independence and keyboard checks also passed with the browser language set to English.
