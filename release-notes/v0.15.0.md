## Sample actors compendium / サンプルアクターのコンペンディウム

**English**
- The sample actors (combat, magic and decking characters, a training NPC, a vehicle and a brand, with their equipment) now come as the **Sample actors** compendium. As the Agonarch, open it in the Compendium tab and drag them into the world, or right-click the pack and choose Import All to bring in all six in a folder. You no longer need to create six empty actors and import a JSON file into each.
- The JSON files are still in the release under `samples/actors/`. The help's "Getting started" page and the sample guide now describe the compendium first.
- Internal: the pack is built from those JSON files at release time, and the version bump also updates `package-lock.json`.

**日本語**
- サンプルアクター(戦闘・魔法・デッキングのキャラクター、訓練用 NPC、乗り物、ブランド。装備つき)を、コンペンディウム「サンプルアクター」として同梱しました。アゴナークはコンペンディウムタブで開いてワールドへドラッグするか、パックを右クリックして「全てをインポート」を選べば、6 体をフォルダーにまとめて取り込めます。空のアクターを 6 体作って 1 つずつ JSON をインポートする必要はなくなりました。
- JSON ファイルも引き続き `samples/actors/` に入っています。ヘルプの「はじめに」とサンプルの説明は、コンペンディウムからの取り込みを先に書きました。
- 内部の変更:パックはリリース時にその JSON から作ります。バージョンを上げる手順で `package-lock.json` も更新するようにしました。

Validation: 142 tests, localization and syntax checks passed, and the release build includes the pack. In Foundry 14.365 with 0.15.0 loaded, all nine browser scripts passed; samples checks that the compendium holds the same six actors as the JSON files and that they import with all their items.
