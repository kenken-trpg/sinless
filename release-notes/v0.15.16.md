## Clearer keyboard focus / キーボードのフォーカス枠

**English**
- Keyboard focus rings on Sinless inputs, selects, textareas, editable content, action links and content-area buttons now use the application theme's primary text color with a 2px outline. This improves visibility on dark surfaces and adapts to light themes.
- Window header buttons keep Foundry's existing focus rings.
- Added `npm run verify -- focus-visibility`, which samples rendered focus-ring contrast in dark and light themes. The full verification run now contains 19 scripts.

**日本語**
- Sinlessの入力欄・選択欄・テキスト欄・編集欄・操作リンク・内容領域のボタンは、キーボードのフォーカス枠をテーマの主文字色で2pxの太さで描くようにしました。暗い背景で見やすく、明るいテーマにも合わせて変わります。
- ウィンドウ上端のヘッダーボタンは、Foundry既存のフォーカス枠を使います。
- 明暗テーマで描画された枠のコントラストを測定する `npm run verify -- focus-visibility` を追加しました。全体の検証は19本です。

Validation: 151 tests, localization and syntax checks, and package build passed. On Foundry 14.365, Japanese and English focus checks each passed 10 samples across dark and light themes (minimum contrast 4.89:1 and 4.95:1 respectively). The English keyboard regression check passed for all actor and item types. The Japanese final check used system 0.15.15 plus these changes after a world restart; English checks used the same source with the server still reporting 0.15.14. These are representative focus-ring samples, not a full obstruction or WCAG conformance audit.
