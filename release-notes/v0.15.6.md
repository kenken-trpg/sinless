## Keyboard verification for dialogs / ダイアログ内のキーボード検証

**English**
- Added browser verification for keyboard interaction inside test, damage, drain and all four digital attack dialogs. Checks cover Tab and Shift+Tab navigation, numeric editing, Space toggles, Enter submission and cancellation.
- Confirmed that cancellation leaves actor state and chat unchanged, including nested defense tests, and that focus returns to the invoking roll button.
- Added `keyboard-dialogs` to the verification runner. The full run now includes 11 scripts. This release adds verification and documentation; runtime behavior is unchanged.
