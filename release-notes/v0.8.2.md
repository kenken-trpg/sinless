## Package listing preparation / パッケージ一覧への登録準備

**English**
- No gameplay changes.
- The manifest now includes `bugs`, `readme` and `changelog` links for the Foundry package listing.
- The release workflow can announce new versions to the Foundry package listing through the Package Release API, once the `FOUNDRY_RELEASE_TOKEN` repository secret is set. Until then, that step is skipped.

**日本語**
- ゲーム内容の変更はありません。
- Foundry のパッケージ一覧向けに、マニフェストへ `bugs`、`readme`、`changelog` のリンクを追加しました。
- リポジトリの Secret `FOUNDRY_RELEASE_TOKEN` を設定すると、リリースのワークフローが Package Release API で新しいバージョンを Foundry の一覧に通知します。未設定の間はこの段階を飛ばします。

Reload after updating. / 更新後は再読み込みのみで使えます。
