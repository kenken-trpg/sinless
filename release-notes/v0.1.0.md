First release of the unofficial Sinless system for Foundry VTT (v13–v14). English and Japanese.

**Install:** in Foundry, *Install System* → paste the manifest URL:
```
https://github.com/kenken-trpg/sinless/releases/latest/download/system.json
```

### Features
- Character and NPC actors: attributes, four dice pools (Brawn / Finesse / Focus / Resolve), physical and stun condition tracks with wound penalties, etiquettes, Kismet pool, Zoetic Potential
- Test dialog: skill + gear limits, bonus/penalty dice, group-skill defaulting (−2), untrained tests, rerolls, Kismet dice, pool spending in conflict
- Chat card with Argle Bargle Foofaraw detection and a button to add Kismet dice after the roll
- Initiative (Reaction + Focus pool successes), NPC static initiative, pools refresh every combat round
- World settings: run difficulty, operational heat, base condition boxes, wound penalties
- Items: weapon, armor, gear, implant, spell/power, ritual, knowledge skill, asset

### Not yet included
Brand / sector play, drones and vehicles, decking, detailed magic rules, compendiums.

This is an unofficial fan project. It contains no rules text; you need the rulebook to play.
