## Preserve unrelated verification chats / 検証時の無関係なチャットを保持

**English**
- The color-independence, contrast and target-size browser checks now delete only the chat card they created. Previously, cleanup deleted all messages added since the check started, including unrelated posts from another session.
- Fixture actor checks use created IDs rather than name prefixes.
- Added the optional `npm run verify -- chat-cleanup` regression check. It runs the three checks while a separate temporary GM session posts a message, then verifies that the unrelated post and pre-existing messages survive cleanup. It runs separately from the 19 checks in `all`.

**日本語**
- 色に依存しない表示・コントラスト・操作対象サイズのブラウザー検証は、自分が作ったチャットカードだけを削除するようにしました。従来は開始後に増えた全メッセージを削除しており、別セッションの無関係な投稿も対象になり得ました。
- 検証用アクターの残存確認は、名前の接頭辞ではなく作成したIDで行います。
- 追加検証 `npm run verify -- chat-cleanup` を用意しました。対象3本の実行中に別の一時GMセッションで投稿し、後片付け後も無関係な投稿と既存チャットが残ることを確認します。`all` の19本とは別に実行します。
